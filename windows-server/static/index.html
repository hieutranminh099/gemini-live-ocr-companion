Kho dịch thuật

Live OCR và Video dùng chung Translation Memory với phạm vi và mức chất lượng rõ ràng.

Translation Memory là cơ chế ghi nhớ và tra cứu, không huấn luyện lại trọng số Gemini. Draft không tự trở thành Verified; bản User Approved không bị AI ghi đè.
